Clip Uploader

A personal tool for the Fifty Fifty YouTube channel.

Clip Uploader runs on one computer and is used by one person: the owner of the Fifty Fifty channel. It uploads finished short clips (with their titles and descriptions) to that channel, sets when each one goes public, and checks their upload status. If an Instagram account owned by the same person is connected, it can post the same clips there as Reels.

It is not a service and is not offered to anyone else. There are no user accounts, sign-ups, ads or tracking.

Clip Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
